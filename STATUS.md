# STATUS.md

## What was built

A local-first **Freebie Shelf**: a kit for organizing the free downloads
you already grabbed (fonts, printables, ebooks, audio), each cataloged with
its download location, license, and plain-English usage rights.

Components:

- `index.html` — static catalog page (generated). Opens via `file://` in any
  browser. Category filter chips, per-item license link, local file path,
  usage-rights badges, and a badge legend. No JavaScript dependencies, no
  server, no signups.
- `data/freebies.csv` — the editable source of truth. Ships with 5 starter
  example entries (marked "example entry") covering font, printable, ebook,
  and audio categories.
- `data/freebies.json` — machine-readable mirror of the CSV, regenerated by
  `build.py` so the two never drift.
- `build.py` — pure-stdlib (Python 3) rebuild tool. Validates schema, writes
  `freebies.json`, and regenerates `index.html` with clear per-line
  errors for bad data (`--check` validates only; `--sync` only updates JSON).
- `templates/catalog-template.html` — the page shell `build.py` fills in.
- `style.css` — print- and mobile-friendly styling.
- `docs/license-types.md` — plain-English guide to free-license types
  (MIT, CC0, CC BY / BY-SA / BY-NC / BY-ND, OFL 1.1, "personal use only",
  marketplace site terms) with red flags and an attribution template.
- `rights-card.html` — one-page printable rights card (print CSS included;
  hides itself nicely in print preview).
- `tests/test_freebies.py` — 29 tests covering schema validation,
  CSV/JSON sync, page rendering (every item present, filter buttons with
  counts, badge legend, no leftover placeholders, hostile-HTML escaping),
  rejection of bad data, and housekeeping (LICENSE wording, README credit,
  no-secret scan of data files).
- `README.md` — full instructions in the same plain-English style as the
  LLC's other work.

## How to run it

```bash
open index.html                                    # the catalog (mac; Windows: start index.html)
python3 build.py                                   # rebuild page + sync JSON after editing CSV
python3 build.py --check                           # validate data only
python3 build.py --sync                            # re-sync freebies.json from CSV
python3 -m unittest discover -s tests -v           # run all 29 tests
```

Requires only Python 3 (stdlib only — no pip installs) and a browser.

## Privacy / safety

- No secrets, API keys, or personal data in any file (covered by a test).
- Everything stays local; the page requires no network and works offline.
- Example `download_location` values are harmless starter paths (`~/Downloads/...`).

## Known gaps

- The catalog renders from the CSV at build time; filtering is client-side,
  but adding a row means re-running `python3 build.py` (one command, works
  fine from `file://`).
- Editing `freebies.json` directly will be overwritten by the next build —
  the CSV is the source of truth by design.
- Starter entries are illustrative examples, not a real person's downloads;
  replace them with your own.
- The license guide covers the common cases, not every possible license
  variant; it links to canonical license pages for the details.
- Search box (as opposed to category filters) not yet implemented; no
  sorting UI on the table yet.
